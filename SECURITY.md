# Private data and security reports

Do not attach a flash dump, NVS partition, ownership ledger, browser profile, raw device
log, conversation database, or recording to a public issue. Remove account tokens,
network details and personal text from a minimal reproduction first.

Local Recorder data and conversations stay on the Module unless the owner exports them.
Only recognized text and the configured conversation context are sent to the paired Muse
service for an ordinary question. Local device commands and their confirmations need no
new Muse request. Optional weather sends the user-configured location to its provider.

Use Recorder only with the permission appropriate to the situation. Screen-off mode is
an explicit local recording workflow, not remote unattended activation.

The project does not introduce a public network control server. Follow upstream security
guidance for device pairing and any optional upstream network features. Report a security
problem privately through GitHub’s security reporting feature if enabled; do not publish
working credentials or private data to demonstrate it.
